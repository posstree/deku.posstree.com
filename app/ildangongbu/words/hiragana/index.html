히라가나 50음도

학습 팁

1주일 안에 마스터하는 순서

1-2일: あ행 ~ な행 (5행) / 3-4일: は행 ~ ん (5행) / 5-7일: 탁음·반탁음 + 종합 복습

읽기부터 익히세요

처음부터 손으로 쓰기에 집착하면 학습 시간이 2-3배 늘어납니다. 먼저 읽기에 익숙해진 후 단어를 통째로 익히며 자연스럽게 쓰기를 익히는 것이 효율적입니다.

매일 짧게 반복

하루에 1시간 몰아서 하는 것보다 매일 10-15분씩 반복하는 것이 기억에 훨씬 오래 남습니다. 일단공부 앱은 짧은 학습 단위로 매일 부담 없이 가나를 반복할 수 있도록 설계되어 있어, 출퇴근·자기 전 자투리 시간에 활용하기 좋습니다.

일단공부 앱에서 더 학습하기

전체 JLPT N1~N5 단어와 음성 발음, 예문, 복습 기능을 일단공부 앱에서 만나보세요. 매일 적당한 분량의 단어 학습과 테스트, 약점 단어 자동 복습으로 가나에 이어 일본어 단어 학습을 꾸준히 이어갈 수 있습니다.
