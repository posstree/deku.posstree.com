업데이트 2026.03.27

v6.11.2 - 즐겨찾기 아이콘 표시 방식 개선

안녕하세요, 「JLPT 일본어 단어 공부, 일단 공부」 개발자 Deku입니다.

v6.11.2 업데이트를 통해 단어 학습 화면의 즐겨찾기 아이콘 표시 방식이 개선되었습니다.

변경 이유

기존에는 즐겨찾기/카테고리에 추가된 수를 숫자 badge로 표시하고 있었습니다. 하지만 학습 중에 숫자가 눈에 들어와 공부에 방해가 된다는 피드백을 받았습니다. 이번 업데이트에서는 숫자 badge를 제거하고, 아이콘 형태만으로 상태를 직관적으로 표현하도록 변경하였습니다.

아이콘 안내
빈 북마크
즐겨찾기 / 카테고리에
추가된 단어가 없는 경우
채워진 북마크
즐겨찾기 / 카테고리에
추가된 단어가 1개인 경우
겹친 북마크
즐겨찾기 / 카테고리에
추가된 단어가 2개 이상인 경우
그 외 변경 사항
  • 앱 안정화 작업을 했습니다.
  • 사용자가 수정한 단어를 반영했습니다.

앞으로도 더 나은 학습 경험을 제공하기 위해 노력하겠습니다. 감사합니다.
