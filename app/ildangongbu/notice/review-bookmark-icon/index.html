업데이트 2026.03.28

v6.11.3 - 복습 화면 즐겨찾기 아이콘 표시 방식 통일

안녕하세요, 「JLPT 일본어 단어 공부, 일단 공부」 개발자 Deku입니다.

v6.11.3 업데이트를 통해 복습(퀴즈) 화면에서도 단어 학습 화면과 동일한 즐겨찾기 아이콘 표시 방식이 적용되었습니다.

변경 내용

v6.11.2에서 단어 학습 화면의 즐겨찾기 아이콘을 숫자 badge 대신 아이콘 형태로 개선하였으나, 복습(퀴즈) 화면에는 기존의 숫자 badge 방식이 그대로 남아있었습니다.

이번 업데이트를 통해 복습 화면에서도 동일한 아이콘 표시 방식과 조작 방식이 적용되어, 앱 전체에서 일관된 사용 경험을 제공합니다.

기능 단어 학습 화면 복습(퀴즈) 화면
아이콘 표시 방식 (빈/채워진/겹친 북마크) v6.11.2 적용 v6.11.3 적용
탭 → 즐겨찾기 추가/해제 v6.11.1 적용 v6.11.3 적용
길게 누르기 → 카테고리에 추가 v6.11.1 적용 v6.11.3 적용
그 외 변경 사항
  • 앱 안정화 작업을 했습니다.
  • 사용자가 수정한 단어를 반영했습니다.

앞으로도 더 나은 학습 경험을 제공하기 위해 노력하겠습니다. 감사합니다.
