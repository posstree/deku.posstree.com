v6.16.0 - 자동 넘어가기 옵션 세분화 및 복습 흐름 개선

안녕하세요, 「JLPT 일본어 단어 공부, 일단 공부」 개발자 Deku입니다.

v6.16.0 업데이트에서는 복습 흐름을 더 세밀하게 다듬었습니다. 자동 넘어가기 옵션을 끔/항상/정답만의 3단계로 세분화하고, 복습 자동 재생 정책을 듣기·읽기 유형에 맞게 정비했습니다. 또한 동기화 적용 시 파트 학습률이 즉시 갱신되도록 수정하고, iOS 외부 음악 정지, iPad 헤더 정렬 등 자잘한 문제도 함께 정리했습니다.

주요 변경 사항
자동 넘어가기 옵션 3단계 세분화

기존의 켜기/끄기 두 단계였던 자동 넘어가기 옵션을 끔 / 항상 / 정답만의 3단계로 세분화했습니다. '정답만' 옵션을 선택하면 정답을 맞혔을 때만 다음 문제로 자동 진행되고, 오답일 때는 화면에 머물러 해설을 충분히 확인할 수 있습니다. 학습 스타일에 맞춰 더 세밀하게 조정해 보세요.

복습 자동 재생 정책 정비

듣기 계열 복습 문제에 진입하면 음성을 자동으로 재생해 별도 조작 없이 바로 학습을 시작할 수 있습니다. 반대로 예문 읽기 복습 문제에서는 자동 재생이 학습 흐름을 방해할 수 있어 자동 재생을 제외했습니다.

파트 학습률 즉시 갱신

자동 동기화 다운로드를 적용한 직후에도 파트 리스트의 학습률이 이전 값에 머물러 있던 문제를 수정했습니다. 이제 다른 기기에서 학습한 진행 상황이 즉시 화면에 반영됩니다.

iOS 외부 음악 정지 문제 재수정

iOS에서 단어 발음을 재생할 때 다른 앱의 음악이 함께 멈추던 문제가 다시 발생하여 재수정했습니다. 음악을 들으면서 학습하는 흐름이 끊기지 않습니다.

iPad 헤더 정렬 미세 조정

iPad 환경에서 헤더의 안전 영역 오프셋을 미세 조정해 좌상단 컨트롤이 시스템 UI와 자연스럽게 정렬되도록 다듬었습니다.

그 외 변경 사항
  • 출처가 표기되지 않은 알림 명언 항목을 정리했습니다.
  • 그 외 앱 안정화 작업을 진행했습니다.

앞으로도 더 나은 학습 경험을 제공하기 위해 노력하겠습니다. 감사합니다.
