v6.10.0 - 전체 복습 문제 유형 복수 선택 기능 추가

안녕하세요, 「JLPT 일본어 단어 공부, 일단 공부」 개발자 Deku입니다.

v6.10.0 업데이트를 통해 전체 복습의 문제 유형을 여러 개 동시에 선택할 수 있는 기능이 추가되었습니다.

변경 내용

기존에는 전체 복습 시 하나의 문제 유형만 선택하여 풀 수 있었습니다. 이번 업데이트를 통해 원하는 문제 유형을 여러 개 선택하여 다양한 유형의 문제를 섞어서 풀 수 있게 되었습니다.

  • 변경 전: 드롭다운에서 하나의 문제 유형만 선택 가능
  • 변경 후: 오른쪽 상단의 「문제 유형」 버튼을 눌러 체크박스로 여러 문제 유형을 동시에 선택 가능
변경 전
변경 후
참고: 프리미엄 단어의 문제 유형

예문이 포함된 문제 유형은 프리미엄 단어를 사용합니다. 무료 사용자의 경우, 프리미엄 단어가 출제되면 아래와 같이 「단어를 보고 의미 맞추기」 문제로 대체되어 표시됩니다.

문제 유형 무료 사용자 대체 유형
예문 빈칸 채우기 단어를 보고 의미 맞추기
예문을 보고 단어 뜻 맞추기 단어를 보고 의미 맞추기
예문보고 단어의 발음 맞추기 단어를 보고 의미 맞추기
예문 의미를 보고 문장 배열 맞추기 단어를 보고 의미 맞추기
예문을 듣고 문장 배열 맞추기 단어를 보고 의미 맞추기
예문 보고 읽기 단어를 보고 의미 맞추기

구독(유료) 사용자는 모든 문제 유형을 프리미엄 단어의 예문과 함께 이용하실 수 있습니다.

이번 업데이트를 통해 더 다양한 방법으로 일본어 단어를 복습하실 수 있습니다. 앞으로도 더 나은 학습 경험을 제공하기 위해 노력하겠습니다. 감사합니다.
