v6.11.1 - 즐겨찾기 및 카테고리 추가 방식 변경

안녕하세요, 「JLPT 일본어 단어 공부, 일단 공부」 개발자 Deku입니다.

v6.11.1 업데이트를 통해 단어 학습 화면에서 즐겨찾기 및 카테고리 추가 방식이 변경되었습니다.

변경 내용

기존에는 즐겨찾기 아이콘을 누르면 즐겨찾기 추가와 카테고리에 추가 화면이 함께 표시되었습니다. 이번 업데이트를 통해 더 직관적이고 빠르게 사용할 수 있도록 조작 방식이 변경되었습니다.

변경 전 (v6.11.0) 변경 후 (v6.11.1)
탭 (짧게 누르기) 카테고리에 추가 화면 표시 즐겨찾기에 바로 추가/해제
길게 누르기 - 카테고리에 추가 화면 표시
사용 방법
  • 즐겨찾기 추가/해제: 단어 학습 화면에서 즐겨찾기 아이콘을 탭(짧게 누르기)하면 즐겨찾기에 바로 추가되거나 해제됩니다.
  • 카테고리에 추가: 즐겨찾기 아이콘을 길게 누르면 카테고리에 추가 화면이 표시되어, 원하는 카테고리를 선택하여 단어를 추가할 수 있습니다.

이번 변경을 통해 자주 사용하는 즐겨찾기 기능을 더 빠르게 사용하실 수 있으며, 카테고리 관리도 길게 누르기로 간편하게 접근하실 수 있습니다.

앞으로도 더 나은 학습 경험을 제공하기 위해 노력하겠습니다. 감사합니다.
