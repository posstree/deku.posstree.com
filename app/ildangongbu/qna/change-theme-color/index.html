앱 기능 관련

Q. 앱의 빨간색이 눈이 아파요. 색상을 변경할 수 있나요?

A.

「JLPT 일본어 단어 공부, 일단 공부」 앱의 아이덴티티를 위해 빨간색을 사용하고 있습니다만, 눈이 아프시다는 분들이 계셔서 메인 색상을 변경하는 기능을 제공해 드리고 있습니다.

메인 색상 변경 방법:

  1. 앱을 실행합니다.
  2. 왼쪽 상단의 설정 아이콘(기어 모양)을 눌러 설정 화면으로 이동합니다.
  3. 설정 화면 상단에 「메인 색상」의 변경 버튼을 확인하실 수 있습니다.
  4. 변경 버튼을 눌러 원하시는 색상으로 변경합니다.

이 기능이 조금이나마 앱을 편하게 사용하시는 데 도움이 되었으면 좋겠습니다.
