앱 기능 관련

Q. 전체 단어 퀴즈 문제 수를 조절할 수 있나요?

A.

현재 「JLPT 일본어 단어 공부, 일단 공부」 앱의 전체 단어 퀴즈 문제 수 조절은 구독(유료) 사용자에게만 제공해 드리고 있습니다.

구독 사용자 유료

앱 설정 화면 하단에 있는 「문제 개수 변경」 기능을 사용하시면 원하시는 문제 개수로 수정하여 사용하실 수 있습니다.

무료 사용자 무료

결과 화면 하단의 「계속 풀기」 버튼을 누르시면, 이전에 푸신 문제와 다른 15개 단어를 추가로 풀 수 있습니다.

구독 사용자와 무료 사용자의 차별성을 두기 위해 문제 개수 조절 기능을 유료 사용자에게만 제공하는 점, 너그러운 마음으로 이해해 주시면 정말 감사하겠습니다.

추가 문의가 있으시면 문의하기를 통해 연락 부탁드립니다.
