결제 관련

Q. 결제했는데 구독이 적용되지 않아요. 어떻게 복원하나요?

A.

현재 「JLPT 일본어 단어 공부, 일단 공부」 앱의 결제 부분은 구글과 애플의 정책(디지털 컨텐츠 판매는 자사의 결제 시스템을 이용해야 한다)에 의해 구글과 애플의 시스템을 이용하고 있습니다.

  • Apple App Store 심사 지침 (섹션 3.1.1 - In-App Purchase)
  • Google Play 결제 정책 안내

결제가 복원이 안 되신다면 다음 절차를 확인 부탁드립니다.

  1. 네트워크 연결 확인
    결제 내역을 확인하는 절차는 네트워크를 통해서 진행됩니다. 앱 사용 시 네트워크(Wi-Fi 또는 모바일 데이터)가 연결되어 있는지 확인 부탁드립니다.
  2. 구매내역 복원하기
    결제 내역이 네트워크를 통해서 확인이 제대로 안 된 경우, 지금과 같은 문제가 발생할 수 있습니다. 이때는 앱을 실행하시고, 오른쪽 상단의 결제 아이콘(카트 아이콘)을 눌러서 결제 화면으로 이동한 후, 결제 버튼 하단의 「구매내역 복원하기」 링크를 클릭합니다.
    구매 버튼이 아닌, 버튼 하단의 링크입니다.
  3. 결제 계정 확인
    그래도 문제가 발생하신다면, 결제 내역은 결제하신 계정(구글 또는 애플 계정)과 연동됩니다. 그래서 결제하신 계정이 스토어에 로그인이 되어 있어야 합니다. 이 부분을 확인 부탁드립니다.
    • 구글 결제 내역 확인 방법
    • 애플 결제 내역 확인 방법
  4. 휴대폰 재부팅
    그래도 결제 복원이 되지 않으면, 휴대폰을 재부팅(전원을 끄고 다시 킴)하고 복원을 시도해 봅니다.
    대부분의 사용자는 휴대폰 재부팅을 통해 문제가 해결되었습니다.
  5. 앱 재설치
    앱을 재설치하고 복원을 시도해 봅니다.
    앱을 재설치하면 공부하신 내역이 삭제됩니다. 재설치 전에 앱의 설정에 있는 백업 기능을 사용해서 데이터를 백업해 주시기 바랍니다.
  6. 구독 구매 버튼 시도
    위 방법으로도 해결이 되지 않으면, 「구독 내역 복원 버튼」이 아닌 구독 구매 버튼을 눌러봅니다. 만약 어떤 메시지가 발생한다면, 스크린샷을 보내주시면 문제를 수정하는 데 정말 큰 도움이 됩니다.
iOS를 사용하시는 경우

특히 과거에 결제하신 이력이 있으면, 이전 결제 이력이 남아서 제대로 결제가 안 되는 경우가 있습니다. 이 경우 다음 절차를 수행하시면 해결이 가능합니다.

  1. 구독 갱신
    휴대폰의 설정 → 최상단의 계정 → 구독 → 갱신하고 싶은 앱 → 갱신
  2. 앱에서 구독 내역 복원
    앱 실행 → 카트 아이콘 → 「구독내역 복원하기」 클릭

바쁘시겠지만 위의 방법으로 복원을 시도해 주시면 정말 감사하겠습니다.

위의 방법을 시도해도 문제가 계속 발생하신다면 문의하기를 통해 다시 한번 연락 부탁드립니다.
